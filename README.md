# Count Even and Odd Numbers in a 1D Array

This C program counts the number of even and odd elements in a one-dimensional array.

## Concepts Used

- One-dimensional array
- for loop
- if-else
- Modulus operator (%)
- Array indexing

## Example

Input:
10 15 20 25 30 35

Output:
Number of even elements = 3
Number of odd elements = 3
